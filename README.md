# Pitch

Офлайн-приложение для репетиций выступлений: история записей привязана к презентации, её версии и таймлайну слайдов.

- PPTX через установленный LibreOffice или PDF, выбранный вручную.
- Подготовка, выступление, пауза, овертайм и локальная запись WebM с целевым разрешением 720p.
- История с превью, тремя оценками и заметками; сравнение двух записей и времени на слайдах.
- Импровизация с темами RU/EN и импортом собственных TXT/CSV.
- Русский и английский интерфейсы, переназначаемые клавиши, светлое/тёмное оформление.

## Установка и сборки

Подписанный релиз пока не выпущен. Готовность платформ и оставшиеся проверки описаны в [релизном списке](docs/RELEASE.md). Артефакты CI являются тестовыми сборками.

Windows требует установленный Microsoft Edge WebView2 Runtime. Установщик Pitch не скачивает его: при необходимости заранее установите [Evergreen Standalone Installer Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). LibreOffice необязателен — можно экспортировать презентацию в PDF самостоятельно.

Для самостоятельной сборки нужны Go из `go.mod`, Node.js 22.13+ (рекомендуется 24 LTS) и Wails CLI 3.1.0:

```sh
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.1.0
wails3 build
```

Запуск разработки — `wails3 dev`. Команды проверок и платформенных сценариев — в [CONTRIBUTING.md](CONTRIBUTING.md).

## Первая тренировка

Добавьте презентацию, проверьте слайды и выберите «Репетировать эту версию». Настройте длительности и начните запись. После сохранения откройте историю, добавьте оценки и заметку. Для сравнения выберите две попытки одного проекта. Режим «Импровизация» работает без презентации.

По умолчанию: Space — старт/пауза, Enter — пропуск подготовки, Esc — отмена, R — новая тема, стрелки — слайды, F — полный экран, Ctrl+H — история. Сочетания изменяются в настройках и не перехватывают ввод в текстовых полях.

## Приватность

Приложение не использует облако, телеметрию, аналитику или автообновление. Ресурсы интерфейса и PDF-рендерер входят в сборку. Камера и микрофон включаются по нажатию старта и освобождаются после завершения, отмены или ухода с тренировки.

Видео, превью и SQLite хранятся в выбранной папке (по умолчанию `Pitch` в домашнем каталоге). Удаление попытки удаляет её видео, превью и запись БД. Автоудаление старых попыток включается явно. Удаление приложения сохраняет данные тренировок. Смена папки данных требует перезапуска и не переносит существующие записи.

Сетевая проверка WebView2 перед релизом ещё не завершена: более ранняя HTTPS-находка требует окончательной атрибуции. Результаты и границы проверки приведены в [NETWORK-CHECK.md](docs/NETWORK-CHECK.md).
