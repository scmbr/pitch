# Проверка сети на Windows

`scripts/netwatch.ps1` — инструмент разработки для наблюдения за TCP-соединениями и UDP-сокетами Pitch и его текущих дочерних процессов, включая WebView2. Он не входит в приложение, не запускает его и не меняет брандмауэр.

Собери приложение командой `wails3 build`, запусти `bin/pitch.exe`, затем в другом PowerShell:

```powershell
Get-Process pitch | Select-Object Id, StartTime
./scripts/netwatch.ps1 -ProcessId 1234 -DurationSeconds 30
```

Подставь PID нужного экземпляра. При отказе в доступе повтори наблюдение из PowerShell с правами администратора. JSON сохраняется в игнорируемую Git папку `data/network/`; существующие отчёты не перезаписываются. Отчёт содержит имена и PID процессов, локальные и удалённые адреса TCP и локальные порты UDP. Не добавляй результаты с локальными данными в Git.

Во время наблюдения открой настройки, смени язык и сохрани настройки. После появления экрана тренировки отдельно проверь камеру, запись, воспроизведение и выход с экрана. Скрипт останавливается по таймеру или при завершении исходного процесса. Ошибка чтения таблиц соединений сохраняется в неполный отчёт и завершает скрипт с ошибкой.

Для сравнения ограничений WebView2 используй одинаковую сборку и сценарий с отдельными чистыми папками данных: без ограничивающих флагов, с текущими флагами и отдельно с `--host-resolver-rules`. Флаги меняются только в локальной диагностической сборке, а не в рабочей конфигурации приложения. Зафиксируй версию WebView2, вариант флагов, длительность, сценарий и результат каждого запуска.

Опрос таблиц соединений может пропустить короткие соединения и процессы. Интервал задаёт паузу между опросами: сами запросы Windows требуют дополнительного времени, особенно первый. Поля `TimestampUtc` и `FinishedAtUtc` каждого замера показывают время начала и завершения запросов. У UDP-сокетов здесь нет адреса назначения, а DNS может обслуживаться системным процессом. Пустой список не доказывает отсутствие трафика. Для завершения проверки нужны также журнал брандмауэра или захват пакетов и сопоставление с деревом процессов. Скрипт не включает и не меняет системное журналирование.

Проверка логики скрипта без доступа к сети и без дополнительных зависимостей:

```powershell
./scripts/netwatch.test.ps1
```
