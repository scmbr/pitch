# Архитектура

> Черновик до завершения этапа 1. После каждого этапа Claude обновляет этот файл, автор проверяет на ревью.

## Слои

```
┌──────────────────────────────────────────┐
│ Фронтенд (WebView): интерфейс, камера,   │
│ MediaRecorder, таймеры, плеер            │
└───────────────┬──────────────────────────┘
                │ вызовы методов Wails (IPC)
┌───────────────▼──────────────────────────┐
│ Go-бэкенд: проекты, попытки, настройки,  │
│ темы, работа с файлами, запуск           │
│ LibreOffice                              │
└───────────────┬──────────────────────────┘
                │
┌───────────────▼──────────────────────────┐
│ Хранилище: SQLite + папка с видео,       │
│ превью и слайдами                        │
└──────────────────────────────────────────┘
```

Тяжёлую работу (захват, кодирование, воспроизведение видео) выполняет WebView и системные кодеки. Go отвечает за данные и файлы.

## Планируемая структура папок

```
/
├── main.go                 # точка входа Wails
├── internal/
│   ├── app/                # методы, доступные фронтенду
│   ├── storage/            # SQLite, миграции, репозитории
│   ├── projects/           # проекты, версии по хэшу
│   ├── attempts/           # попытки, таймлайн слайдов
│   ├── topics/             # наборы тем, импорт
│   ├── slides/             # конвертация pptx/PDF в картинки
│   └── settings/           # настройки и их хранение
├── frontend/
│   └── src/
│       ├── screens/        # тренировка, история, проект, сравнение, настройки
│       ├── components/
│       ├── lib/            # таймеры, запись, горячие клавиши
│       └── i18n/           # ru, en
├── migrations/
└── docs/
```

Структура уточняется на этапе 1.

## Хранение данных

Папка данных настраивается пользователем:

```
<data>/
├── pitch.sqlite
├── videos/<attempt_id>.webm
├── thumbs/<attempt_id>.jpg
└── slides/<project_id>/<version>/<n>.png
```

## Схема БД (набросок)

- `projects`: id, name, type (`pptx` | `free`), pptx_path, created_at
- `project_versions`: id, project_id, file_hash, version_number
- `attempts`: id, project_id, version_id, video_path, thumb_path, duration_sec, topic, scores (json), note, created_at
- `slide_timings`: attempt_id, slide_index, start_sec, end_sec
- `topic_sets`, `topics`: набор, текст, категория, сложность
- `settings`: ключ-значение

## Ключевые потоки

**Запись попытки.** Фронтенд включает камеру, `MediaRecorder` пишет чанки, по завершении видео передаётся в Go и сохраняется файлом. Таймлайн слайдов фронтенд накапливает в памяти и отправляет вместе с видео. Камера освобождается при выходе с экрана.

**Версии презентации.** При открытии проекта Go считает хэш pptx. Если он отличается от последней версии, создаётся новая запись в `project_versions`, слайды переконвертируются.

**Конвертация слайдов.** Go проверяет наличие LibreOffice, запускает его в headless-режиме, результат кэшируется по хэшу. Если LibreOffice нет, приложение предлагает загрузить PDF.

## Приватность и сеть

Сетевых запросов нет. Ограничение задаётся CSP и конфигурацией Wails. Все ресурсы вшиты в сборку.
