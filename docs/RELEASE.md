# Подготовка релиза

Продуктовые этапы 1–7 реализованы. Релиз пока не считается завершённым.

## Подтверждённые проверки

- Windows: тесты Go, golangci-lint, проверка Svelte, тесты фронтенда и production-сборка.
- Настоящий WebView2 с тестовыми устройствами: запись 1280×720, пауза, овертайм, очистка потоков; история, просмотр, оценки, удаление; PDF-слайды, версии и таймлайн; сравнение; импровизация; настройки и перезапуск.
- Конвертер LibreOffice: тест процесса с отдельным профилем и фикстурой исполняемого файла. Установленного LibreOffice на проверенной машине нет.
- Полный PDF/медиасценарий с тестовыми устройствами повторён вместе с NetLog и WFP/TCPIP/WinHTTP: последний захват без потерь не выявил внешних соединений подтверждённых процессов. Более ранняя HTTPS-находка по одному PID остаётся не объяснённой; подробности и ограничения — в [NETWORK-CHECK.md](NETWORK-CHECK.md).

## Упаковка

Windows: установить NSIS для разработки и запустить `wails3 task windows:package INSTALL_SCOPE=user`. Установщик требует WebView2, но не загружает его. Отсутствующий Runtime завершает установку с кодом 66; пользователь устанавливает Standalone Runtime отдельно.

macOS: `wails3 task darwin:package`, затем `wails3 task darwin:package:dmg`. После настройки собственной подписи — `wails3 task darwin:sign:notarize`. Наличие строк разрешений и правильного имени исполняемого файла в bundle проверяется отдельно от фактического предоставления разрешений системой.

Не публикуйте тестовые сборки как подписанный стабильный релиз. Результаты CI и локальные диагностические отчёты не заменяют проверки физических устройств.
