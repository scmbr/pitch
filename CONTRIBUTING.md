# Contributing

Спасибо за интерес к проекту. Pitch полностью офлайн: любые изменения, добавляющие сетевые запросы, телеметрию или внешние ресурсы, не принимаются.

## Быстрый старт

1. Установи Go, Node.js и Wails (см. документацию Wails для своей ОС).
2. `git clone` и `wails dev`.
3. Тесты: `go test ./...`, линтер: `golangci-lint run`.

Для работы с pptx желателен установленный LibreOffice, но приложение должно работать и без него.

## Ветки

- `feat/короткое-описание` для новых функций
- `fix/короткое-описание` для исправлений
- `docs/короткое-описание` для документации

Прямые пуши в `main` закрыты, всё идёт через pull request.

## Коммиты

[Conventional Commits](https://www.conventionalcommits.org/), сообщения на английском:

```
feat: add slide timeline recording
fix: release camera when leaving the training screen
docs: update architecture overview
```

Мелкие коммиты лучше больших. Перед коммитом запусти тесты и линтер.

## Pull request

- Одна задача на PR.
- В описании: что изменено и зачем, как проверить.
- Если менялась структура, обнови `docs/ARCHITECTURE.md`.
- Если принято нетривиальное решение, добавь запись в `docs/decisions/`.
- Пользовательские изменения отражай в `CHANGELOG.md`.

## Принципы проекта

- **Офлайн.** Никакой сети.
- **Лёгкость.** Никаких фоновых процессов, камера включается только на экране тренировки.
- **Приватность.** Данные пользователя остаются у него. Удаление означает удаление файла с диска.
- **Новые зависимости** добавляются только при необходимости, с объяснением в PR.

## Новые наборы тем

Темы пишутся самостоятельно, без копирования из книг и чужих сайтов, по одной на строку.
